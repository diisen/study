# NCEA Level 2 Physics - DC Electricity Interactive Learning Lab ⚡

ニュージーランド高校2年生（NCEA Level 2 Physics AS 91173 / 2.6 - DC Electricity）の学習を支援するインタラクティブ学習Webアプリケーションです。

---

## 🌟 主な機能 (Key Features)

1. **⚡ 電子＆エネルギー可視化シミュレータ (Particle & Energy Simulation)**
   - 電圧の定義公式 $V = \frac{\Delta E}{q}$ に基づき、電荷（電子 $e^-$）が運ぶエネルギーパック（$\Delta E$, Joules）をリアルタイムにアニメーション描画。
   - 電圧スライダーや抵抗スライダーを操作すると、電子の流速・電球の光・発熱・各メーターの数値が連動。
   - **💥 Blow Lamp（電球の断線実験）**: 直列回路（回路全体停止 $0\text{ A}$）と並列回路（他ブランチは独立して流れる）の違いを体感。

2. **📖 SciPad ワークブック問題演習 (Bilingual Workbook Solutions)**
   - SciPad p.266〜269 の全問（Q1〜Q7h）を収録。
   - 問題文: **英語** (NCEA公式形式)
   - 解説: **丁寧な日本語** (物理概念と途中式)
   - 解答: **英語 ＆ 日本語** のバイリンガル表示
   - ワンクリックで該当の回路状態をシミュレータにロード可能。

3. **📐 公式マジック・トライアングル (Formula Triangle & Calculator)**
   - $V = \frac{\Delta E}{q}$, $I = \frac{q}{t}$, $V = IR$ の公式ピラミッド。
   - 求めたい文字をクリックすると公式が自動変形し、スライダー操作で途中式と単位付き計算結果がリアルタイム更新。

4. **🎯 NCEA Excellence 英語論述ガイド (Exam Key Phrases)**
   - NCEAの記述問題で最高評価（Excellence）を獲得するための必須英語フレーズとキーワードを解説。

---
